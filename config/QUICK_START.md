# Быстрый старт: Настройка gamma для спутников

## 🎯 Зачем это нужно?

**Gamma** - угол радиовидимости спутника. От него зависит:
- Размер зеленого конуса вокруг КА
- Когда БПЛА "видит" спутник и рисует желтую линию

## ⚡ Быстрая настройка

### 1. Добавить новый тип спутников

Откройте `config/satellite_gamma_config.xml` и добавьте:

```xml
<satellite_group>
    <name>Мой спутник</name>
    <pattern>MYSAT|МОЙ-СПУТ</pattern>
    <orbit_altitude>600</orbit_altitude>
    <gamma>15.0</gamma>
    <description>Описание</description>
</satellite_group>
```

**Параметры:**
- `pattern` - часть имени спутника (из TLE)
- `gamma` - угол в градусах

### 2. Изменить gamma для существующей системы

Найдите нужную группу и измените значение gamma:

```xml
<!-- Было: -->
<gamma>8.2</gamma>

<!-- Стало: -->
<gamma>15.0</gamma>
```

### 3. Проверить результат

Запустите программу и смотрите логи:

```
КА IRIDIUM 33 → группа: Iridium | gamma: 15.0 ° (из конфигурации)
```

## 📊 Типичные значения gamma

| Тип системы | Высота | Gamma |
|-------------|--------|-------|
| LEO связь (Иридиум, Гонец) | 700-1500 км | 5-15° |
| Навигация (ГЛОНАСС, GPS) | 19000-23000 км | 12-15° |
| ДЗЗ (фотосъемка Земли) | 400-700 км | 20-30° |
| МКС, низкие орбиты | 300-500 км | 25-35° |

## 🔧 Если что-то не работает

1. **Gamma не применяется:**
   - Проверьте путь: `config/satellite_gamma_config.xml`
   - Проверьте логи при запуске

2. **Pattern не находит спутник:**
   - Посмотрите точное имя спутника в TLE
   - Используйте `|` для нескольких вариантов: `IRIDIUM|IRIDUM|IRD`

3. **Конус слишком большой/маленький:**
   - Уменьшите gamma для узкого конуса
   - Увеличьте gamma для широкого конуса

## 💡 Примеры pattern

```xml
<!-- Иридиум (все спутники) -->
<pattern>IRIDIUM</pattern>

<!-- ГЛОНАСС (Cosmos 2xxx) -->
<pattern>GLONASS|COSMOS 2</pattern>

<!-- Несколько вариантов написания -->
<pattern>GONETS|ГОНЕЦ|GONEC</pattern>

<!-- Точное совпадение с номером -->
<pattern>IRIDIUM 33|IRIDIUM-33</pattern>
```
