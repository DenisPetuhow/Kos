# Конфигурация угла радиовидимости (gamma) для спутников

## Описание

Файл `satellite_gamma_config.xml` содержит настройки угла радиовидимости (gamma) для различных типов спутниковых систем.

**Gamma** - половина угла конуса радиовидимости спутника в градусах.

## Как это работает

### 1. Автоматическая загрузка

При создании объекта `CPaint3D` конфигурация автоматически загружается из `config/satellite_gamma_config.xml`.

Если файл не найден - используется автоматический расчет gamma из высоты орбиты.

### 2. Определение gamma для спутника

Для каждого спутника программа:

1. **Извлекает имя** из TLE данных (например: `IRIDIUM 33`, `GLONASS-M 756`)
2. **Ищет совпадение** с шаблоном в XML (регулярное выражение)
3. **Применяет gamma** из найденной группы

Если совпадение не найдено → gamma рассчитывается автоматически по формуле:
```
gamma = arcsin(R_EARTH / (R_EARTH + h))
```

### 3. Пример работы

**Спутник:** `IRIDIUM 33 DEB`

```xml
<satellite_group>
    <name>Iridium</name>
    <pattern>IRIDIUM|ИРИДИ</pattern>
    <orbit_altitude>780</orbit_altitude>
    <gamma>8.2</gamma>
</satellite_group>
```

**Результат:** gamma = **8.2°** (из конфигурации, не из расчета)

---

**Спутник:** `UNKNOWN-SAT-123`

**Результат:** gamma = **автоматический расчет** из высоты орбиты

## Структура XML

```xml
<satellite_group>
    <name>Название группы</name>
    <pattern>Регулярное выражение для поиска</pattern>
    <orbit_altitude>Высота орбиты (км)</orbit_altitude>
    <gamma>Угол радиовидимости (градусы)</gamma>
    <description>Описание системы</description>
</satellite_group>
```

### Параметры:

- **name** - читаемое название группы (для логов)
- **pattern** - regex для поиска в имени спутника (case-insensitive)
- **orbit_altitude** - справочная информация о высоте орбиты
- **gamma** - реальный угол радиовидимости (учитывает ограничения антенны)
- **description** - описание системы

## Добавление новой группы спутников

### Пример: добавление группы CubeSat

```xml
<satellite_group>
    <name>CubeSat</name>
    <pattern>CUBESAT|CUTE|QARMAN</pattern>
    <orbit_altitude>400</orbit_altitude>
    <gamma>35.0</gamma>
    <description>Малые спутники формата CubeSat</description>
</satellite_group>
```

### Шаги:

1. Откройте `config/satellite_gamma_config.xml`
2. Добавьте новую секцию `<satellite_group>` перед `<default>`
3. Укажите **pattern** - регулярное выражение для распознавания имени
4. Укажите **gamma** - угол радиовидимости в градусах
5. Сохраните файл
6. Перезапустите программу

## Почему gamma отличается от геометрического?

### Геометрический gamma (из высоты):

```
gamma_геом = arcsin(R_EARTH / (R_EARTH + h))
```

**Пример для Иридиум (h=780км):**
- gamma_геом ≈ **63°**

### Реальный gamma (из конфигурации):

- gamma_реальный = **8.2°**

### Разница объясняется:

1. **Диаграмма направленности антенны** - антенна КА работает эффективно только в узком конусе
2. **Минимальный угол возвышения** - на горизонте качество связи плохое
3. **Мощность передатчика** - слабый сигнал не достигает края геометрической зоны
4. **Атмосферное ослабление** - у горизонта сигнал проходит через больше атмосферы

## Примеры gamma для разных систем

| Система | Высота (км) | gamma геом. | gamma реальный | Причина разницы |
|---------|-------------|-------------|----------------|-----------------|
| Иридиум | 780 | 63° | 8.2° | Ограничение антенны |
| Гонец | 1400 | 55° | 10° | Ограничение антенны |
| ГЛОНАСС | 19100 | 14.5° | 14.5° | Близко к геометрии |
| GPS | 20200 | 13.9° | 13.9° | Близко к геометрии |
| МКС | 420 | 74° | 30° | Ограничение связи |
| Starlink | 550 | 67° | 25° | Оптимизация покрытия |

**Вывод:** Для LEO спутников связи реальный gamma сильно меньше геометрического!

## Логирование

При загрузке конфигурации в консоль выводятся сообщения:

```
Загружено 15 групп спутников из конфигурации gamma
  Загружена группа: Гонец | pattern: GONETS|ГОНЕЦ | gamma: 10 °
  Загружена группа: ГЛОНАСС | pattern: GLONASS|COSMOS 2|ГЛОНАСС | gamma: 14.5 °
  ...
```

При обработке спутников:

```
КА IRIDIUM 33 → группа: Iridium | gamma: 8.2 ° (из конфигурации)
КА UNKNOWN-123 → gamma: 25.3 ° (автоматический расчет, h=500 км)
```

## Отладка

### Если gamma не применяется:

1. **Проверьте путь к XML:**
   - Файл должен быть: `config/satellite_gamma_config.xml`
   - Относительно исполняемого файла программы

2. **Проверьте логи:**
   - Должно быть: `"Конфигурация gamma успешно загружена"`
   - Если нет - проверьте путь к файлу

3. **Проверьте pattern:**
   - Pattern должен соответствовать имени спутника
   - Используйте regex-тестер для проверки

4. **Проверьте синтаксис XML:**
   - Все теги должны быть закрыты
   - Нет недопустимых символов

### Принудительная загрузка:

```cpp
paint3d.loadGammaConfig("config/satellite_gamma_config.xml");
```

## Совместимость

- **Qt 5.x** и выше (требуется `QXmlStreamReader`)
- Файл XML должен быть в кодировке **UTF-8**
- Поддерживаются комментарии в XML (`<!-- комментарий -->`)

## Пример полной обработки

```
[Загрузка программы]
→ CPaint3D() создается
→ loadGammaConfig("config/satellite_gamma_config.xml")
→ Загружено 15 групп спутников

[Обработка спутников]
→ calc() вызывается
→ Для каждого КА:
   1. Извлечь имя: "IRIDIUM 33"
   2. Извлечь высоту: 780 км
   3. Поиск в конфигурации: найдена группа "Iridium"
   4. Применить gamma = 8.2° (вместо 63° из расчета)
   5. Создать зеленый конус с углом 8.2°
   6. БПЛА использует тот же угол для проверки видимости
```

## Техническая справка

### Почему это важно для видимости БПЛА-КА:

1. **Зеленый конус** отображает зону радиовидимости с gamma из конфигурации
2. **Проверка видимости БПЛА** использует тот же gamma:
   ```cpp
   if(Elevation > gamma) → КА видим
   ```
3. **Линия от БПЛА к КА** рисуется только если БПЛА внутри конуса

Если gamma неправильный → линии будут появляться/исчезать неправильно!
