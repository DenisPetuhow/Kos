# Kos — моделирование орбитальной группировки и радиовидимости БПЛА-КА

Программа на Qt + OpenSceneGraph/osgEarth: 3D-моделирование движения космических
аппаратов (КА) по TLE или Кеплеровым элементам, движения БПЛА по поверхности Земли
и их взаимной радиовидимости в реальном времени.

## Возможности

- Загрузка группировок из TLE (примеры: `iridium.txt`, `Gonez.txt`), прогноз SGP4/SDP4;
- 3D-сцена: вращающаяся Земля, орбиты, модели КА, **зеленые конусы** — зоны покрытия;
- БПЛА: полет по дуге большого круга, 3D-модель, маршрут, подпись;
- **Желтые линии видимости БПЛА-КА**: строятся, когда БПЛА входит в конус покрытия КА
  (проверка по надирному углу — та же геометрия, что у конуса), исчезают при выходе;
- Угол радиовидимости gamma per-КА: из `config/satellite_gamma_config.xml` (по имени,
  regex) или геометрически `asin(R/(R+h))` из фактической высоты орбиты;
- График числа видимых КА по времени (гистограмма);
- Режим камеры «следовать за Землей».

## Самое важное

| Что | Где |
|-----|-----|
| Координатор сцены (создание КА, конусов, БПЛА) | `paint3d.cpp` |
| Зона покрытия КА (конус: ось на надир, r = h·tanγ) | `gui3D/addcone.cpp` |
| БПЛА + линии видимости (надирный угол < γ) | `gui3D/add_bpla.cpp` |
| Баллистика: SGP4, Кеплер, преобразования СК | `ASD/` |
| Конфигурация gamma по типам КА | `config/satellite_gamma_config.xml` |

Ключевое соглашение: **конус и проверка видимости используют один и тот же gamma
(в градусах) и одну и ту же геометрию (надирный угол)**. Gamma записывается в
`m_ka[i].bsa[0].gamma` в `CPaint3D::calc()` ДО создания БПЛА.

## Сборка

Проект qmake: `view_project.pro` (Qt 5, OpenSceneGraph, osgEarth, GDAL, GSL — пути
библиотек настроены под MinGW/MSYS2, см. секцию LIBS). Файл
`config/satellite_gamma_config.xml` должен лежать рядом с исполняемым файлом или в
рабочей директории (программа перебирает несколько типовых путей и пишет в лог,
откуда загрузила конфигурацию).
