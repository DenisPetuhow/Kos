# Структура программы Kos

Программа моделирует орбитальную группировку космических аппаратов (КА), движение БПЛА
по поверхности Земли и взаимную радиовидимость между ними в 3D (OpenSceneGraph + osgEarth + Qt).

## Поток данных (главная цепочка)

```
TLE-файл (iridium.txt)
   │  mainwindow: парсинг → ASDScStleInitData → m_VecOrbobj
   ▼
CPaint3D::setKa(m_VecOrbobj)  →  m_ka
   ▼
CPaint3D::calc()              для каждого КА:
   │   1. ASDOrbitalVehicle ka(m_ka[i])          - объект прогноза движения
   │   2. idVeh = i+1                            - уникальный ID
   │   3. высота h из getKep() → gamma из XML или asin(R/(R+h))
   │   4. gamma → m_ka[i].bsa[0].gamma           - ДО calc_bpla()!
   │   5. new addOrbit(ka)                       - орбита
   │   6. new ASDOrbitVeh3D(ka, par)             - модель КА
   │   7. new addCone(ka, bse, mapK)             - зеленый конус (тот же gamma)
   ▼
CPaint3D::calc_bpla()         для каждого БПЛА:
   │   1. new add_BPLA(m_BpLA[i], m_page)
   │   2. setKaList(m_ka)                        - список КА с заполненным bsa
   ▼
Таймер → CPaint3D::repaint(t) → ASDScene3D::repaintObjects3D(t)
   │   каждый объект.repaint(t):
   │   - КА двигается по орбите (SGP4/Кеплер) в АГЭСК
   │   - конус следует за КА, ось на надир
   │   - БПЛА двигается по дуге большого круга в ГСК
   │   - add_BPLA::updateVisibilityLines(t):
   │        для каждого КА: isKaVisible (надирный угол < gamma?)
   │        да  → желтая линия БПЛА-КА в m_root_agsk
   │        нет → линия удаляется
   ▼
Земля вращается: moveEarth(t) поворачивает m_root_gsk на звездное время
```

## Системы координат

| Система | Описание | Кто в ней живет |
|---------|----------|-----------------|
| GEO     | Географическая (lat, lon, h) | Исходные позиции БПЛА, ОКИК |
| ГСК (GSC) | Гринвичская, вращается с Землей, км | БПЛА, наземные точки, m_root_gsk |
| АГЭСК (AGESC) | Абсолютная геоцентрическая экваториальная, инерциальная, км | КА, орбиты, конусы, линии видимости, m_root_agsk |
| ТСК (SSC/TSC) | Топоцентрическая от наблюдателя | Расчет азимут/угол места |

Переходы: `convGeoToGsc`, `convGscToAgesc(coord, t)`, `convAgescToGsc(coord, t)`,
`convGscToSsc(coord, lat, lon, A)`. Параметр `t` нужен, т.к. угол между ГСК и АГЭСК —
это звездное время `compSiderealTime(t)`.

В 3D-сцене OSG координаты в **метрах** (км × 1000).
